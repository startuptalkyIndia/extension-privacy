MediaFinder — Privacy Policy

Last updated: 2026-10-24 (version 0.1.0)

MediaFinder is a Chrome extension that shows an inventory of the images, video and audio used by the web page in your current tab, with sizes and quality checks, and lets you save plain direct files you have the right to keep. It is an inspector. It does not download streaming video.

What MediaFinder reads

Only when you click the MediaFinder icon, it reads the page in that one tab: the page's image, video and audio elements, their sources, the page's CSS background images, icon and social-image tags, links to media files, and the browser's own network timing records for the page (which files loaded and how big the browser measured them). Nothing read this way is stored or sent to us. It uses Chrome's activeTab permission, so it has no access to any other tab and no standing access to any website.

What is stored, and where

The inventory is built in memory and shown in the popup; when the popup closes it is gone. MediaFinder does not save your browsing history or the pages you inspect. The only things kept, in your browser's local extension storage on your device, are three small counters for the rating reminder described below: the install date, how many times you have run a scan, and whether the reminder was dismissed.

What is sent over the network

Nothing is sent to the developer. MediaFinder has no server, no account system, no analytics and no advertising. It can make these requests, all of them to the sites that already host the files shown, and only in these cases:

  • For files on the page's own site whose size the browser did not measure, a small HEAD request (or, if refused, a request for one byte) for the file's size, made from the page itself. That site sees an ordinary same-site request.

  • For files on other sites, only if you press "Check sizes": Chrome asks your permission for those specific sites, MediaFinder sends a HEAD request (no cookies) to each, and the access is removed afterwards. Those sites can see the request, as they would any request for their file.

  • When you press "Save" on a file, your browser downloads that one file, as if you had clicked a download link.

Saving files, and what MediaFinder refuses

Save works only for a plain direct file served as an ordinary http(s) address. It never saves streams (HLS, DASH, blob or MediaSource), never merges segments, never works around DRM or a sign-in, and offers no saving at all on a built-in list of major streaming, music and social platforms. Please save only files you have the right to keep.

Uninstall page

When you remove MediaFinder, Chrome opens a page on our policy site (startuptalkyindia.github.io). The address contains only the extension name, its version and its ID. Nothing else is sent from the page; it shows an optional "what went wrong?" form that only opens an email draft you can choose to send. The website host may keep ordinary access logs, as any website does.

Rating reminder

After at least 7 days and 10 scans, the popup shows one small card asking if you would like to rate MediaFinder on the Chrome Web Store. It is shown the same way to everyone, offers no reward, appears only inside the MediaFinder popup (never on websites), and is shown at most twice: once, then once more 30 days after "Not now". "Don't ask again" ends it. It uses only the local counters above, which are never sent anywhere.

Copy and download

"Copy URLs" and "Copy Markdown" put text on your clipboard when you press the button. "CSV" and "JSON" save a file in your Downloads folder when you press the button. These stay on your device. What you do with them afterwards is up to you.

What we do not do

We do not sell or share data, use it for advertising, use it to judge creditworthiness, or transfer it to anyone. MediaFinder does not load or run remote code.

Permissions

activeTab (read the tab you click the icon on), scripting (run MediaFinder's own packaged functions in that tab), downloads (save the one plain direct file you press Save on), storage (the local counters for the rating reminder). No host permissions at install. Optional access to other sites is requested only when you press "Check sizes", for the sites named, and removed afterwards.

Changes

If this policy changes, the date above changes and the new text is published at the same address.
